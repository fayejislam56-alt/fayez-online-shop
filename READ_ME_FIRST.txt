FAYEZ ONLINE SHOP - MAC ONE-CLICK STARTER

1. Extract this ZIP in Downloads.
2. Double-click Install_and_Run.command.
3. If macOS blocks it, right-click it and choose Open, then choose Open again.
4. The launcher looks for your existing folder:
   ~/Downloads/Fayez Online Shop 4
5. It checks that shop.db or fayez_online_shop.db already exists before continuing.
6. It backs up the old app.py, copies the updated app.py, creates a private Python virtual environment, installs requirements, and starts the site.
7. Keep the Terminal window open. Visit http://127.0.0.1:5001

IMPORTANT:
- It does NOT delete or replace shop.db / fayez_online_shop.db.
- It stops if it cannot find the existing database.
- A backup of the previous app.py is created before replacement.
- The app source has passed Python syntax compilation. Live launch against your Mac database has not been tested here.
- Product prices marked as estimates are not official brand MRPs. Confirm supplier prices and physical stock before accepting orders.
